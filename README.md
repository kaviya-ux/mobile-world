# Mobile World

Mobile World is a beginner-friendly static website for exploring smartphones by budget, specifications, and product details.

## Pages

- `index.html` - Home page
- `category.html` - Smartphone listings by price range
- `best-specs.html` - Phones grouped by strong specifications
- `accessories.html` - Mobile accessories
- `about.html` - About the project
- `contact.html` - Contact page
- `sign-in.html` - Sign-in form demo
- `products/` - Individual phone detail pages

## Folder Structure

- `assets/images/site/` - General website images and icons
- `assets/images/phones/` - Phone product images
- `products/` - Product detail HTML pages

## How To Open

Open `index.html` in a browser. Since this is a static website, no build step is needed.

## Notes

The product pages include a small JavaScript gallery: clicking a thumbnail swaps it with the main phone image.
